邮箱 AI 助手

摘要、翻译、添加标签和辅助撰写邮件。

软件版本

本地辅助程序安装

需要单独安装 Windows x64 辅助程序（MSI）。下载后手动安装，重启 Thunderbird，再登录或填写 API Key。

Thunderbird 管理插件更新；辅助程序仍使用独立更新机制。已安装本插件时，无需再次安装 MSI 中附带的 XPI。

下载辅助程序（Windows x64）隐私政策

使用 AI 功能时，相关邮件内容会通过本地辅助程序发送到所选服务商，可能消耗额度。自动摘要和标签默认关闭；可按账户启用。缓存和导出保留在本机。

AI 摘要

用于手动摘要和新邮件自动摘要，独立于界面及翻译语言；跟随系统时优先使用系统语言。

新邮件自动摘要

在账户右键菜单中勾选“自动为新邮件生成 AI 摘要”可启用。所有账户默认关闭；仅处理收件箱的新邮件，使用当前模型与摘要语言，并消耗套餐或 API 额度。

每天按本地日期重置，默认 100 封，可设置 1–1000。失败和取消的请求也计数；缓存命中和手动摘要不计数。超过上限的邮件不会自动补处理。

翻译

选择原文语言或自动识别；摘要语言在摘要设置中选择。

区域或多服务资源必须填写 Region，例如 westeurope；全局资源留空。

获取 API Key

DeepL 根据 Key 自动识别 API Free 或 Pro。

分别加密保存各服务商的密钥。所选服务商已配置时优先使用；否则使用原 AI 模型。请求失败时不自动切换服务。使用量与费用以服务商套餐为准。

标签

用于之后自动生成的标签，不修改已有标签。

标签别名

将别名映射到已有标签。忽略大小写及多余空格，按完整名称匹配；不修改历史邮件或确认前手动编辑的标签。

例如：ZUB Helena、Helena Ultra 分别填写一行，目标标签选择 Helena。每个别名最多 32 个字符，每个标签最多 100 个别名。

    新邮件自动标签

    在邮箱主界面右键账户名称，选择“AI 助手 → 自动标记新邮件”以开启或关闭。仅处理已启用账户收件箱的新邮件，新账户默认关闭，不扫描历史邮件。使用当前提供商、模型及标签语言；启用后自动发送邮件主题和正文，消耗套餐或 API 额度。

    导出邮件

    ChatGPT 自动附加为实验功能；其他应用只打开程序，需手动添加文件。

    仅统计和清理本插件已完成的导出文件，保留其他文件及导出中的文件。

    缓存

    缓存长期保存在本机。再次打开时优先使用匹配的结果；点击重试才重新生成。清除缓存后需重新生成。

    辅助程序更新已下载。点击安装后，请关闭 Thunderbird，再确认管理员授权。
