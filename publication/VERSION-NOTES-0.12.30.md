# Mail AI Assist 0.12.30

Select Ollama in Settings to run summaries, translations, tag suggestions and compose rewrites with your chosen model. The helper connects to `http://localhost:11434` by default. Enter a custom server URL to use another computer, including an HTTPS endpoint on Tailscale. Save the address and select an installed model from the list.

Install the matching Thunderbird 148+ XPI and helper. Windows x64 uses the multilingual MSI. macOS 13+ packages are available for Apple Silicon and Intel for manual installation. The MSI is not Authenticode-signed. Both macOS packages are unsigned and unnotarized.
