# Mail AI Assist 0.12.31

Remote Ollama servers now require HTTPS, including servers on a LAN or VPN. If you previously saved a remote HTTP address, open Settings, select Ollama, enter the server's HTTPS address, refresh the list and select a model. Existing cached results remain readable.

Local Ollama still defaults to http://localhost:11434. HTTP is accepted only on localhost, IPv4 loopback (127.0.0.0/8) or IPv6 loopback ([::1]), with an explicit port.

Update both the Thunderbird 148+ extension and the native helper, then restart Thunderbird. Choose the Windows x64 MSI or the macOS 13+ PKG for Apple Silicon or Intel. The Windows installer is not Authenticode-signed. The macOS packages are unsigned and unnotarized.
